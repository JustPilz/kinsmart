# Kinsmart — каталог моделей

Локальный каталог коллекции Kinsmart: данные в `models.json`, картинки в `models/`, просмотр через `index.html`.

## Файлы данных

| Файл | Назначение |
|------|------------|
| `models.json` | Основной каталог продуктов (ключ — id с официального сайта) |
| `my-collection.json` | Личная коллекция |

## Слоты изображений (`image_slots`)

Имена исходных файлов и пути в каталоге приводятся к трём слотам:

| Слот | Значение |
|------|----------|
| `photo` | Фото модели (`-photo`, `-website` или без суффикса упаковки) |
| `tray` | Display box, 12 шт. (`_P12_l`, `KT####D`, `KT####D{variant}`) |
| `box` | Window box, 1 шт. (`W{variant}`, `_P1_l`, `-box`) |

В каталоге пути обычно вида `models/{item_no}/{item_no}-photo.jpg`, `-tray.jpg`, `-box.jpg`.

## Модификаторы артикула (`modifiers`)

Суффиксы после базового номера `KT####` (например `KT5057**FB**`, `KT7002**FS1**`). Могут комбинироваться слева направо.

| Код | Значение |
|-----|----------|
| `W` | Window box — в имени исходного файла `W{variant}` = фото window box |
| `D` | Display box, 12 шт. — префикс в имени: `KT####D…` или суффикс `_P12_l` |
| `P12_l` | Display box, 12 pcs (суффикс `_P12_l`) |
| `P1_l` | Window box, 1 pc (то же, что `W`) |
| `F` | Flower — раскраска «цветочек» |
| `B` | Big foot |
| `S1` | Surfboard |
| `Y` | Pastel Color |
| `P` | Police |
| `C` | Неизвестно (встречается, напр. `KT7002C`) |
| `E` | Неизвестно |

### Примеры разбора

- `KT5057B` → модификатор `B` (big foot).
- `KT5057FB` → `F` + `B` (flower + big foot).
- `KT5057FBS1` → `F` + `B` + `S1`.
- `KT7002FS1` → `F` + `S1` (без `B`).
- Базовый артикул без суффикса (`KT5004`, `KT5333`) — без модификаторов.

## Запуск

```bat
run-web-server.bat
```

Откройте `index.html` через локальный сервер (иначе загрузка JSON может блокироваться браузером).
